## 四、为什么做 W12

用户原话：「为什么搞了这么多，我的云看起来还是有很强的颗粒感，总感觉是体素化的」。

诊断：W10（cloud-only 输出、世界尺度步进）与 W11（时域升采样）只改采样调度与帧间复用，从未提高密度场空间分辨率或增加渲染期细节，颗粒/体素感本就不该被它们改善。

数字见设计文档 §2：96³ 缓存覆盖 160 km × 12 km ⇒ 水平约 1667 m/voxel；全局 `detailStrength` 默认 0 ⇒ 渲染期细节全关；`rayMarchSteps: 64` ⇒ 步长千米级；W10B 世界尺度步进默认关闭。

## 五、5 项 owner 决定（不可更改；细节见设计文档 §3）

1. 视觉靶子 = **carve**：团块被雕出结构，按密度全域 remap，非等值面窄带贴皮。
2. 光照密度 = **rough**：main ray 用 finalDensity；light march 与 ground shadow 用 roughDensity。
3. `worldStepEnabled` **默认开启**纳入 W12，同一 Gate 内重采基线。
4. **膨胀 + 纯减法侵蚀**（dilate-then-erode），增益膨胀而非下移阈值。
5. 首轮只覆盖 **Billow**（Cu/Sc/Ac 完整预算并校准）；Stratiform/Cellular 极弱；Ci/Cb 幅度 0，等 W15/W16。

采纳方案 A（单次 `remapClamped`）；Billow 可选叠加 C 的 turbulence warp；放弃方案 B（两次 threshold，与 roadmap §17.4 冲突）。
